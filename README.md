### 🚀 Featured Production & Engineering Systems

#### ⚙️ [Workflow Engine — Persistent Backend Workflow System](https://github.com/osmanbinabubakar/workflow-engine)

TypeScript + Fastify backend system for state-based business workflows. Persistent workflow definitions and instances with SQLite, transition rules and actions, audit history, REST APIs, automated tests, Docker support, and GitHub Actions CI.

#### 🚌 [EC Safe Ride — School Fleet & Transport Logistics](https://github.com/osmanbinabubakar/Safe-Ride-School-Bus-Management) — [Live](https://ecsaferide.com)

Multi-app ecosystem (Driver, Parent, Admin) — Flutter + Firebase + Riverpod. Built a 3-layer GPS throttling engine that cut DB writes by 70% while keeping 60 FPS marker gliding. Offline-first with Hive, QR manifest boarding, DVIR.

#### ⏱ [ShiftSense — Workforce Management & Kiosk Engine](https://github.com/osmanbinabubakar/shiftsense)

Cross-platform attendance running on dedicated tablets — React Native (Expo) + TypeScript. Zero-trust hardware binding, GPS geofencing, PIN punch with haptics. Admin portal — Next.js App Router + Supabase with multi-tenant isolation.

#### 🚗 [RideFlow — Luxury Chauffeur & Dispatch Radar](https://github.com/osmanbinabubakar/RideFlow)

Next.js, React, Prisma, Postgres. Live dispatcher radar on Google Maps, flight-delay telemetry (JFK/LGA/EWR), and Stripe pre-authorization.
